JobPilot

Copiloto de búsqueda de empleo con IA

Adaptar el CV y la carta a cada oferta es lento. JobPilot lo automatiza: sube tu CV, pega una oferta y te dice cuánto encajas, qué te falta y te prepara una carta adaptada.

  • Perfil estructurado a partir del CV en PDF, que el usuario revisa antes de guardar.
  • Extracción de requisitos de la oferta y análisis de encaje: la IA clasifica y Java calcula la puntuación.
  • Carta y CV adaptados con versiones y exportación a PDF.
  • Tablero kanban para seguir cada candidatura.
  • Tests unitarios, de integración, de frontend y E2E con Playwright; CI con GitHub Actions.

CineExplorer

Aplicación web para explorar películas con la API de The Movie Database: buscas por título, filtras por género, ves el detalle de cada película y guardas tus favoritas.

  • Búsqueda reactiva con RxJS (debounceTime, switchMap, combineLatest, forkJoin).
  • Componentes standalone, rutas con parámetros y lazy loading.
  • Favoritos persistentes en localStorage y desplegada en GitHub Pages.
